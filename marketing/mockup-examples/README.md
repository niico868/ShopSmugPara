# Mockup examples

Reference pairs that show the AI what "good" looks like. See `../MOCKUP-RECIPE.md` section 7.

- `flat-lay/`: clean white studio flat-lays (the default style)
- `campaign-frame/`: "SCANNING" drop cards

Name files `NN-<garment>-<colour>-before.jpg` / `-after.png`, plus an optional `NN-notes.md`.
Rejected attempts: `NN-<garment>-<colour>-rejected.png`, with a note on why.

Note: campaign-frame examples 01 and 02 are missing their "before" photos. Add them when available.
